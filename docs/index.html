Said No · a plugin for the open-source Bifrost AI gateway · Tavily for web access

Your no stays no.

A user tells an AI assistant what not to do. A web page the assistant reads tells it to do exactly that. Said No reads only the user's own messages and blocks the refused action at the gateway, quoting the user's words. How it decides

1 · The agent

Any model behind Bifrost does the task, reading pages through Tavily's MCP server. It never sees the rules.

2 · The extractor

A small model reads only messages from the user and writes each refusal or permission as a rule with the user's exact words.

3 · The validator

Code drops any rule, or any narrowing of one, that can't point at the user's own words. Web pages can't create or lift a rule.

4 · The matcher

Code rules on every tool call before it runs. The latest thing the user said wins. A blocked call never reaches the tool.

Code, tests and raw results: github.com/JannetEkka/said-no. Attack wording and goals adapted from AgentDojo (MIT). Action tools in the suite are inert decoys: they record the call and run nothing.
